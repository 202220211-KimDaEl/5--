*{} 은 모든 태그에 적용하는 것. 폰트나 보드 설정을 이걸로 할 수 있음.

.nav .logo와 .nav .menu도 있어서 nav 사용법도 a태그 처럼 봐두는 게 좋을 듯. 
nav{
	logo{ }
}
와 
nav{
	>logo{ }
}
는 다르다. 자세한 건 니니한테 물어보기.
예제에서 수정되었으니 어떤식으로 썼는지 확인해보기. 이름이 .nav . logo 같은게 아니더라도 nav안에 있는 logo 기능을 쓸 수 있게 들여쓰기로 해주는 거인듯.적용은 샌드박스처럼. 코드블럭처럼.

masonry 그리드: 벽돌쌓는 듯한 그리드-예시 핀터레스트

grid-template-columns: 1fr 1fr 1fr 1fr;
grid-template-columns: 1fr 100px 1fr 1fr;
grid-template-columns: repeat(4, 1fr);
적용하면 그리드인데 각 박스들의 크기를 일부 설정할 수 있음.
근데 예제처럼 grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
auto-fit이 제일 무난한듯 minmax으로 최소 작아지게 하는 단위도 좋고.
